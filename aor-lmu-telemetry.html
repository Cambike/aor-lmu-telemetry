Set up your telemetry library

  1. In LMU, turn on Automatically Record Telemetry. Each session is saved as its own .duckdb file.
  2. Run Setup AOR LMU Telemetry.cmd once (game closed). It moves Telemetry and player\Settings to C:\Users\<you>\AOR LMU Telemetry and links them back, because browsers are not allowed to open anything inside Program Files.
  3. Click Choose library folder and pick C:\Users\<you>\AOR LMU Telemetry. The tool remembers it and picks up new sessions automatically.
